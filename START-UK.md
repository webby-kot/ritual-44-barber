# Ritual 44 — локальний прототип заявок

## Запуск
Потрібен Python 3.11 або новіший. Відкрийте термінал у папці проєкту та виконайте:

    python server.py

Сайт: http://127.0.0.1:8844
Панель: http://127.0.0.1:8844/admin.html
Ключ адміністратора створюється у private/admin-key.txt. Його вводять у панелі; не публікуйте його. Дані зберігаються у private/bookings.sqlite. Папку private не можна завантажувати в GitHub.

## Що працює
Форма з послугою, майстром, бажаними датою й часом; перевірка даних; збереження SQLite; захищений список заявок; статуси new / confirmed / cancelled. Зміна статусу не надсилає клієнту підтвердження: адміністратор зв'язується окремо. Це заявка, а не резервування вільного місця.

## Канали повідомлень
Налаштовуються змінними середовища перед запуском. Ніколи не вставляйте секрети у script.js або GitHub.
- NOTIFY_CHANNELS: email або telegram або email,telegram
- Telegram: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
- Пошта SMTP SSL: SMTP_HOST, SMTP_PORT (типово 465), SMTP_USER, SMTP_PASSWORD, MAIL_FROM, MAIL_TO
- ADMIN_TOKEN: постійний сильний ключ адміністратора (інакше генерується при запуску)

Без налаштувань заявки зберігаються, панель показує not_configured. При помилці доставки — failed; автоматичних повторів наразі немає. Telegram перевірено 6 листопада 2026: тестова заявка з браузера збережена, Telegram API підтвердив надсилання. Пошта ще не підключена. Локальний файл private/telegram.json містить ключ і chat_id; він не входить до архіву чи GitHub.

## Перевірено
Подання тестової заявки через браузер, збереження й зміна статусу через API, відхилення порожньої заявки та некоректного статусу, відмова доступу без ключа, недоступність приватних файлів. Перевірено синтаксис JavaScript. Мобільний екран 390 px переглянуто, меню відкривається та закривається; на 390 і 320 px не виявлено горизонтального переповнення документа. Це браузерна перевірка, не тест на фізичному телефоні.

## Перед публічним запуском
Це локальний навчальний прототип, сервер слухає лише 127.0.0.1. GitHub Pages не запускає Python. Для публічної версії потрібні серверний хостинг із HTTPS, захист від спаму й обмеження запитів, резервні копії, надійні сесії адміністратора та політика обробки контактних даних. Також треба підключити й перевірити канали доставки. Сайт на GitHub не змінений.
